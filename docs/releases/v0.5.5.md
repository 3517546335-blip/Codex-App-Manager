# Codex Desktop 管理器 v0.5.5

> 修复 Windows 中文副本启动后立即退出、最终仍显示英文客户端的问题。

## Windows 中文化

- **释放单实例锁**：一键配置和中文副本启动前会强制结束当前用户的 `ChatGPT.exe`、`Codex.exe` 与相关 helper，避免启动请求被仍在运行的英文 MSIX 实例接管。
- **正确的启动目录**：使用中文副本的应用目录作为工作目录启动，与已验证的社区汉化启动方式保持一致。
- **兼容 Electron 进程交接**：启动器进程快速退出时，会检查中文副本目录下是否已有实际应用进程，避免把正常的进程交接误报为失败。
- **保留无权限流程**：仍不修改 `WindowsApps`，不需要管理员权限、Node.js 或在线下载语言包。

已经生成过 `v0.5.4` 中文副本的用户无需清理文件。更新管理器后再次点击“一键配置”，管理器会关闭英文实例并直接启动现有中文副本。

本次发布提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包。Windows 安装包暂未配置 Authenticode 发行者签名，首次运行可能出现 SmartScreen 提示。
