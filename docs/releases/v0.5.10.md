# Codex Desktop 管理器 v0.5.10

## Windows 下载线路优化

- 内置更新源按“主镜像 -> Microsoft 官方 CDN -> R2”顺序自动切换。
- Microsoft CDN 临时地址由公开发布仓库定时刷新，安装包不写死过期链接。
- 官方地址必须与镜像 manifest 的版本、包名、架构和大小完全一致。
- 下载后继续执行 SHA-256、Microsoft Authenticode 和 MSIX Identity 校验。
- 自定义更新源不参与自动切换，macOS 更新逻辑保持不变。

## 下载与安全

- Microsoft FE3 当前返回 HTTP 下载地址；仅允许无重定向的
  `*.dl.delivery.mp.microsoft.com/filestreamingservice/files/` 地址。
- 元数据仍通过 HTTPS 获取，任一校验失败都会拒绝安装并回退 R2。
- 当前只发布 Windows x64，不新增 Windows ARM64 构建。
