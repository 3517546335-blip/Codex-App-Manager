# Codex Desktop 管理器 v0.5.2

> Windows 一键配置现在可直接启用 Codex/ChatGPT 客户端内置的简体中文资源，不依赖 Node.js，也不需要另行下载语言包。
> One-click setup on Windows can now activate the Simplified Chinese resources bundled with Codex/ChatGPT, without Node.js or a separate language-pack download.

## 亮点 · Highlights

- **Windows 原生中文化**：一键配置会验证并修改客户端的 `app.asar`，同步更新 ASAR 文件偏移与 SHA-256 完整性信息；找不到唯一补丁位置时会停止，不会盲目修改未知版本。
  Native Windows localization: one-click setup verifies and patches the client's `app.asar`, updating file offsets and SHA-256 integrity metadata. It stops instead of modifying an unknown build when the patch location is not unique.

- **无需 Node.js 或语言包下载**：补丁由管理器内置的 Rust 引擎完成，使用客户端已经包含的 `zh-CN` 菜单和 WebView 资源。
  No Node.js or language-pack download: the bundled Rust engine applies the patch using the `zh-CN` menu and WebView resources already present in the client.

- **可重复执行并保留备份**：首次补丁会保留原始 `app.asar`；再次点击会识别已完成状态。客户端升级替换 `app.asar` 后，再点击一次即可为新版本重新应用。
  Idempotent with backups: the original `app.asar` is preserved on the first patch and later clicks detect the completed state. After a client update replaces `app.asar`, run one-click setup again to patch the new version.

## 修复 · Fixes

- **关闭客户端后再写入**：管理器先请求目标安装目录中的 Codex/ChatGPT 正常退出，等待后仅结束仍未关闭的对应进程；无论关闭结果如何，S1API/DonaAPI 配置仍会写入。
  Close before writing: Manager first asks Codex/ChatGPT processes from the detected installation to exit normally, then ends only matching processes that remain. S1API/DonaAPI configuration is still written regardless of the close result.

- **修复 Windows 备份落盘权限错误**：备份和便携版暂存文件现在使用符合 Windows 要求的可写句柄同步，避免 `Access is denied (os error 5)`。
  Fix Windows backup flush permissions: backup and portable staging files now use writable handles when syncing, avoiding `Access is denied (os error 5)`.

## 安装与升级 · Install & Upgrade

**已经安装？** 打开“设置 -> 关于”，点击“检查管理器更新”。
**Already installed?** Open Settings -> About and select Check for Manager Updates.

| 平台 · Platform | 安装包 · Installer |
| --- | --- |
| macOS · Apple Silicon | 在下方 Assets 选择名称含 `macOS_aarch64.dmg` 的文件 |
| macOS · Intel | 在下方 Assets 选择名称含 `macOS_x86_64.dmg` 的文件 |
| Windows · x64 | 在下方 Assets 选择名称含 `Windows_x64-setup.exe` 的文件 |

Windows 中文化功能仅在 Windows 版本中启用；macOS 版本保持原有配置行为。Windows 安装包尚未配置 Authenticode 发行者签名，首次运行可能出现 SmartScreen 提示。macOS 包未配置 Apple Developer ID 公证时，可执行：

```bash
sudo xattr -dr com.apple.quarantine "/Applications/Codex Desktop 管理器.app" && open "/Applications/Codex Desktop 管理器.app"
```

The Windows localization feature is Windows-only; macOS keeps the existing configuration behavior. The Windows installer does not currently carry an Authenticode publisher signature, so SmartScreen may appear on first launch.
