# Codex Desktop 管理器 v0.5.8

> 修复部分 Windows 电脑创建中文副本时提示“无法加密指定的文件（os error 6000）”的问题。

## Windows 中文化

- **绕过 WindowsApps EFS 属性**：不再使用会尝试继承源文件加密属性的系统文件复制流程，改为读取文件内容并在用户目录创建普通文件。
- **不携带受保护属性**：中文副本不会继承 WindowsApps 文件的 EFS、只读或 ACL 属性，避免目标目录不支持相同加密方式时中断。
- **保持无管理员权限**：不修改 WindowsApps 原文件，不需要管理员权限、Node.js 或在线语言包。
- **完整失败清理**：复制任一文件失败时仍会清理临时副本，不会把不完整应用识别为已汉化版本。

出现过 `os error 6000` 的用户更新管理器后，重新点击“一键配置”即可。

本次发布提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包。Windows 安装包暂未配置 Authenticode 发行者签名，首次运行可能出现 SmartScreen 提示。
