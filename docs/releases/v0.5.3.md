# Codex Desktop 管理器 v0.5.3

> 修复 Windows Store/MSIX 版 Codex 中文化无法替换 `app.asar` 的问题。
> Fix Windows Store/MSIX localization failing to replace `app.asar`.

## 修复 · Fixes

- **兼容 WindowsApps 原位覆盖**：不再尝试在受保护的 MSIX 目录中新建和重命名临时文件；管理员助手只对现有 `app.asar` 临时取得写权限，并使用 Windows 二进制复制原位覆盖。
  WindowsApps-compatible in-place replacement: the elevated helper no longer creates and renames sibling files inside the protected MSIX directory. It temporarily grants write access only to the existing `app.asar` and overwrites it using Windows binary copy.

- **失败自动恢复**：覆盖失败或安装后哈希不匹配时，立即使用管理器数据目录中的原始备份恢复。
  Automatic rollback: a failed overwrite or post-install hash mismatch immediately restores the pristine backup stored in Manager's data directory.

- **兼容加密的 Store 文件**：原始 `app.asar` 通过字节流写入备份，不继承 WindowsApps 的 EFS/加密属性，避免 Windows 错误 6000。
  Encrypted Store-file compatibility: the original `app.asar` is streamed into the backup without inheriting WindowsApps EFS attributes, avoiding Windows error 6000.

- **显示真实失败阶段**：管理员助手会返回具体阶段和 Windows 异常信息，不再只显示笼统的“代码 27”。
  Actionable diagnostics: the elevated helper now reports the exact stage and Windows exception instead of only a generic code 27.
