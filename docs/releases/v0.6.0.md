# Codex Desktop 管理器 v0.6.0

> 三个平台安装器现已内置对应架构的官方 Codex，安装过程不再下载 Codex 主程序。
> Each platform installer now embeds the matching official Codex package, so Codex is no longer downloaded during installation.

## 亮点 · Highlights

- **真正离线安装**：Windows x64、macOS Apple Silicon 和 macOS Intel 分别内置对应架构的官方 Codex 完整包。
  Windows x64, macOS Apple Silicon, and macOS Intel each carry the matching complete official Codex package.
- **保留一键配置**：S1API 一键配置继续可用，Windows 版继续包含现有中文化流程。
  One-click S1API configuration remains available, including the existing Windows localization flow.
- **精简管理器**：移除 Codex 皮肤功能和在线 Codex 更新源选择，安装与升级只使用当前安装器内置版本。
  Codex skins and online Codex source selection are removed; install and upgrade operations use the version embedded in this installer.
- **轻量更新提醒**：管理器每 24 小时从 GitHub 检查一次新版本；发现新版后只打开飞书教程页，不在应用内下载安装或重启管理器。
  The manager checks GitHub once every 24 hours and opens the Feishu guide when a newer installer exists; it never installs or restarts itself in-app.
- **S1API 入口保留**：首页继续显示“让每一次 AI 调用更简单”和 `https://s1api.com`。
  The S1API homepage entry remains visible with `https://s1api.com`.

## 安装 · Install

| 平台 · Platform | 文件 · Asset |
| --- | --- |
| Windows x64 | [CodexDesktopManager_S1API_v0.6.0_Windows_x64.rar](https://github.com/q4549286/Codex-Desktop-Releases/releases/download/v0.6.0/CodexDesktopManager_S1API_v0.6.0_Windows_x64.rar) |
| macOS Apple Silicon | [CodexDesktopManager_S1API_v0.6.0_macOS_aarch64.rar](https://github.com/q4549286/Codex-Desktop-Releases/releases/download/v0.6.0/CodexDesktopManager_S1API_v0.6.0_macOS_aarch64.rar) |
| macOS Intel | [CodexDesktopManager_S1API_v0.6.0_macOS_x86_64.rar](https://github.com/q4549286/Codex-Desktop-Releases/releases/download/v0.6.0/CodexDesktopManager_S1API_v0.6.0_macOS_x86_64.rar) |

RAR 均无密码，每个压缩包只包含对应平台的 EXE 或 DMG 安装器。其余 EXE、DMG、`.app.tar.gz`、`.sig` 和 `latest.json` 是兼容旧版本与自动更新所需的发布工件。

macOS 包未配置 Apple Developer ID 签名时，可在拖入“应用程序”后执行：

```bash
sudo xattr -dr com.apple.quarantine "/Applications/Codex Desktop 管理器.app" && open "/Applications/Codex Desktop 管理器.app"
```

本页 Assets 同时提供 `SHA256SUMS`。Windows 安装器可能触发 SmartScreen；Tauri `.sig` 仅用于发布完整性校验，不代表 Windows Authenticode 发布者签名。
