# Codex Desktop 管理器 v0.5.9

> 同步上游 v0.5.1，修复 Codex 26.727 桌面版的皮肤主画布兼容问题。

## 主题兼容

- **适配新版主画布标记**：优先识别 Codex 26.727 的 `data-app-shell-main-surface`，避免把背景、人物立绘和舞台内容挂到错误的 `main` 元素。
- **兼容旧版客户端与皮肤包**：继续支持旧版 `main.main-surface`，现有 `.codexskin` 无需重新打包。
- **安全清理兼容标记**：切换或停用皮肤时，只移除管理器自己添加的兼容属性和类名。

## 发行说明

- 保留 S1API 广告与一键配置。
- 保留 Windows 离线中文化逻辑。
- 保留 macOS `ChatGPT.app` 安装、旧路径迁移和启动检测修复。
- 本次发布提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包，不包含 Windows ARM64。

Windows 安装包暂未配置 Authenticode 发行者签名，首次运行可能出现 SmartScreen 提示。macOS 安装包未经过 Apple 公证，必要时仍可执行：

```bash
sudo xattr -dr com.apple.quarantine "/Applications/Codex Desktop 管理器.app" && open "/Applications/Codex Desktop 管理器.app"
```
