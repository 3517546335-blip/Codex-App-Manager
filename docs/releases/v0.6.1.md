# Codex Desktop 管理器 v0.6.1

> 修复部分 Windows 电脑一键中文化失败或误选 MSIX 安装目录的问题。
> Fixes one-click localization failures and incorrect MSIX target selection on some Windows PCs.

## 修复 · Fixes

- **处理安全扫描占用**：复制完整 Codex 应用后，管理器会对 Windows 错误码 `5`、`32`、`33` 执行有限延迟重试，避免 Defender、索引器或其他扫描程序短暂占用目录时直接报“拒绝访问”。
  After copying the complete Codex application, the manager now retries transient Windows errors `5`, `32`, and `33` with bounded delays instead of failing immediately while Defender, indexing, or another scanner briefly holds the directory.
- **portable 目录优先**：选择 portable 模式且安装目录有效时，一键配置会优先中文化该目录并自动登记，不再被旧 MSIX 或 WindowsApps 记录覆盖。
  When portable mode points to a valid installation, one-click configuration now localizes and adopts that directory before considering stale MSIX or WindowsApps records.
- **保留失败现场**：中文副本最终仍无法激活时，管理器会保留工作目录并记录源路径、目标路径和 Windows 错误码，方便继续恢复和排查。
  If activation still fails after all retries, the working copy is retained and its source path, destination path, and Windows error code are logged for recovery and diagnosis.
- **官方安装不受影响**：MSIX 中文化继续使用用户目录中的独立副本，不修改或删除 Microsoft Store 安装。
  MSIX localization still uses a separate per-user copy and does not modify or remove the Microsoft Store installation.

RAR 均无密码，每个压缩包只包含对应平台的 EXE 或 DMG 安装器。其余 EXE、DMG、`.app.tar.gz`、`.sig` 和 `latest.json` 是兼容旧版本与自动更新所需的发布工件。

macOS 包未配置 Apple Developer ID 签名时，可在拖入“应用程序”后执行：

```bash
sudo xattr -dr com.apple.quarantine "/Applications/Codex Desktop 管理器.app" && open "/Applications/Codex Desktop 管理器.app"
```
