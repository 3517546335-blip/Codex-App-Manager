# Codex Desktop 管理器 v0.5.4

> 重做 Windows Store/MSIX 中文化流程，解决提示成功但重启后仍为英文的问题。

## Windows 中文化

- **不再修改 WindowsApps**：保留官方 MSIX 安装不动，将当前版本的完整应用复制到用户可写目录后离线补丁，不再请求管理员权限。
- **无需 Node.js 或语言包下载**：直接使用官方安装包已经内置的 `zh-CN` 菜单和 WebView 资源。
- **一键配置后自动启动**：写入 S1API 配置与 `desktop.localeOverride = "zh-CN"`，关闭现有 ChatGPT 进程，完成后直接启动中文副本。
- **管理器启动按钮自动识别**：存在与当前官方版本匹配的中文副本时，“启动 Codex”会优先打开该副本。
- **兼容客户端升级**：副本按官方安装路径和版本隔离；官方客户端升级后再次点击“一键配置”即可重建，新副本启用后会清理旧副本。
- **同步 ASAR 完整性信息**：如果 `ChatGPT.exe` 内嵌了 `app.asar` 哈希，管理器会在副本中同步更新，避免补丁后立即退出。

本次发布提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包。Windows 安装包暂未配置 Authenticode 发行者签名，首次运行可能出现 SmartScreen 提示。

## 安装与升级

已经安装管理器的用户可打开“设置 → 关于”，点击“检查管理器更新”。手动安装请在下方 Assets 选择对应系统的 `.exe` 或 `.dmg`；`.app.tar.gz`、`.sig` 和 `latest.json` 是自动更新器工件。
