# Codex Desktop 管理器 v0.5.7

> 修复 Codex `26.721.30844` 更新后，一键配置提示“Webview 中文开关实际找到 0 处”的问题。

## Windows 中文化

- **兼容新版资源结构**：官方将中文初始化逻辑从 `app-main-*` 移到了 `app-initial-*`。管理器现在按初始化特征定位实际 bundle，不再依赖固定文件名。
- **保留严格校验**：只有唯一同时包含 `enable_i18n` 与 `locale_source` 初始化逻辑的文件才会被修改；找不到或出现多个候选时仍会停止，避免写坏 `app.asar`。
- **兼容旧版 Codex**：旧版 `app-main-*` 结构和新版 `app-initial-*` 结构均已使用真实 `app.asar` 完整改写验证。
- **继续保持离线与无管理员权限**：不需要 Node.js，不下载语言包，也不修改受保护的 `WindowsApps` 原文件。

受影响用户更新管理器后，再次点击“一键配置”即可重新生成中文副本。

本次发布提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包。Windows 安装包暂未配置 Authenticode 发行者签名，首次运行可能出现 SmartScreen 提示。
