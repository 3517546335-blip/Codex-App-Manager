> 这一版让一键配置更稳定: Sub2api 配置会按预设完整重写,避免旧配置残留造成冲突。
> This release makes one-click configuration more predictable: the Sub2api preset now rewrites the Codex config cleanly instead of leaving stale settings behind.

## ✨ 亮点 · Highlights

- **一键 Sub2api 配置重写**: 点击一键配置后,`~/.codex/config.toml` 会写入一份干净的 Sub2api 预设,包含模型和网络配置。
  One-click Sub2api config rewrite: the button now writes a clean `~/.codex/config.toml` preset covering model and network settings.

## 🐛 修复 · Fixes

- **避免旧配置冲突**: 不再尝试逐行合并已有配置,减少注释项、旧 provider 或残留模型字段导致的配置混乱。
  Avoid stale config conflicts: the app no longer merges line by line, reducing confusion from commented keys, old providers, or leftover model settings.

## 📦 安装与升级 · Install & Upgrade

**已经安装?** 由于本分支从这一版开始使用新的 updater 签名密钥,请手动安装一次 v0.2.5;之后的版本即可继续走应用内自动更新。
**Already installed?** This fork starts using a new updater signing key in v0.2.5, so install this version manually once; later releases can continue through in-app updates.

| 平台 · Platform | 下载 · Download |
| --- | --- |
| macOS · Apple Silicon | 在下方 Assets 选择 `CodexAppManager_aarch64.dmg` |
| macOS · Intel | 在下方 Assets 选择 `CodexAppManager_x86_64.dmg` |
| Windows · x64 | 在下方 Assets 选择 `CodexDesktopManager_x64-setup.exe` |

**Windows 签名状态:** Windows x64 安装包当前没有 Authenticode 代码签名,首次运行可能出现 SmartScreen 提示;`.sig` / `latest.json` 里的 Tauri updater 签名只用于应用内自更新的字节校验,不代表 Windows 发行者信任。详情见 [Windows signing and verification](https://github.com/Wangnov/Codex-App-Manager/blob/main/docs/windows-signing.md)。
**Windows signing status:** The Windows x64 installer is not Authenticode-signed yet, so SmartScreen may warn on first run; the Tauri updater signature in `.sig` / `latest.json` verifies in-app update bytes only and is not Windows publisher trust. See [Windows signing and verification](https://github.com/Wangnov/Codex-App-Manager/blob/main/docs/windows-signing.md).

**macOS 打开提示:** 当前免费构建未做 Apple 公证。如果系统提示“已损坏，无法打开”，安装到应用程序后运行 `sudo xattr -dr com.apple.quarantine "/Applications/Codex Desktop 管理器.app" && open "/Applications/Codex Desktop 管理器.app"`。
**macOS open note:** This free build is not Apple-notarized. If macOS says the app is damaged, install it to Applications and run `sudo xattr -dr com.apple.quarantine "/Applications/Codex Desktop 管理器.app" && open "/Applications/Codex Desktop 管理器.app"`.

**核验下载:** 本页 Assets 带有 `SHA256SUMS`;Windows 用 `Get-FileHash .\CodexDesktopManager_x64-setup.exe -Algorithm SHA256`,macOS 用 `shasum -a 256 CodexAppManager_aarch64.dmg`,再与 `SHA256SUMS` 比对。
**Verify downloads:** This release includes `SHA256SUMS` in Assets; on Windows run `Get-FileHash .\CodexDesktopManager_x64-setup.exe -Algorithm SHA256`, and on macOS run `shasum -a 256 CodexAppManager_aarch64.dmg`, then compare with `SHA256SUMS`.
